# App Mente em Equilíbrio — Gestão de Avaliação Neuropsicológica

Sistema integrado de **CRM de Leads**, **Gestão de Processos de Avaliação Neuropsicológica (Checklist por Cliente e Visão Geral por Etapas)**, **Geração Automática de Contratos** e **Painel Epidemiológico/Estatístico**, projetado para hospedagem na **Hostinger (PHP + MySQL)** com deploy contínuo via GitHub (`coordenacaosg/appmenteemequilibrio`).
